# 三项十进制拼接平方和问题：临界层偶边二进赋值冲刺

## 0. 范围、记号与结论

本文只研究临界层

\[
(\delta _2,\delta _3)=(-1,1),\qquad N_L=1
\]

中的两个尚未处理的二进边模板

\[
\mathrm Q:\ 2\mid q,\qquad
\mathrm G:\ 2\mid g.
\]

按任务约定，本文暂时接受
`proved_results_report_v2.md`、`proved_results_index_v2.md`、
`critical_layer_final_campaign.md`、`kernel_free_branch_campaign.md` 和
`cauchy_gram_defect_campaign.md` 中的 T1–T18、K5、CG1–CG6，
不作统一独立审计。本文不研究严格层，也不返回高斯下降、Vieta 变换、
有限单元传递或连续间隙。

记

\[
m=\beta _2\ge2,\qquad n=\beta _3\ge1,\qquad
T=10^m,\qquad Y=10^n,\qquad M=m+n.
\]

临界权为

\[
P=X=TY,\qquad Q=10Y.
\]

本文的最终分类是

\[
\boxed{\mathrm{E4}}.
\]

准确含义如下。

1. Q 模板没有关闭，也没有得到 \(m,n,a=v_2(q)\) 的统一上界；
   但其三平方二进型被完全确定，且得到一个模 \(16\) 的精确数字块门。
2. G 模板没有整体关闭，也没有得到 \(n\) 或 \(a=v_2(g)\) 的统一上界；
   但四个循环方程状态都被精确正规化，并关闭了若干完整无界赋值子模板。
3. 特别地，下列完整子状态无解：
   \[
   \begin{aligned}
   &v=2,\quad v_2(g)=1,\\
   &v=1,\quad 0<v_2(u)<m,\quad v_2(g)=1,\\
   &v=1,\quad v_2(u)>m,\quad v_2(g)=1.
   \end{aligned}
   \]
   这些状态在 \(m,n\) 上原本均可无界，故这是 E4 而不是只有新公式的 E5。
4. Q、G 的剩余状态仍含无界参数；本文没有把两个模板压成有限多个
   系数固定的整数方程，也没有找到原题解。

全文仍按三个阶段组织，每阶段至多三个核心新引理：

- 阶段 I：Q 正规化、G 正规化、循环方程四状态；
- 阶段 II：三平方赋值定理、Q 完整赋值、G 四状态分类；
- 阶段 III：只作十三首块、位数窗、反例攻击与最终收束，不另立新引理。

## 2. Q 模板正规化

### 2.1 阶段 I 核心引理 QN：Q1–Q3

假设 \(2\mid q\)。由 \(q,r,g\) 两两互素，

\[
2\nmid rg.
\]

若 \(2\mid v\)，则 (1.5) 强迫 \(2\mid rg\)，矛盾；故 \(v\) 为奇数。
由 (1.7)，奇数 \(rv\) 整除 \(b_1\in\{1,2\}\)，因此

\[
\boxed{r=v=1.}
\tag{2.1}
\]

这是 Q1。注意这里没有把一般的 \(rv\mid b_1\) 错写成 \(r=v=1\)：
真正使用了 Q 模板中 \(r,v\) 都为奇数。

K5 的十进制素数位置定理给出

\[
2\mid q\Longrightarrow \nu(u)=m+n=M.
\tag{2.2}
\]

也可直接从循环门 \(q\mid g+rU\) 看出：\(g,r\) 为奇数，故 \(U\) 必为
奇数，而 \(U=10^M/u\)，所以 \(u\) 吸收 \(10^M\) 的完整二进部分。
因此写成

\[
\boxed{
q=2^a q_0,\qquad u=2^M u_0,
}
\tag{2.3}
\]

其中

\[
a\ge1,\qquad q_0,u_0,g\ \text{均为奇数}.
\]

因 \(u\mid10^M\)，实际还有

\[
u_0=5^e,\qquad 0\le e\le M.
\tag{2.4}
\]

这证明 Q2。代入 (1.8) 得

\[
\boxed{
b_2=b_1qu,\qquad b_3=b_1gu.
}
\tag{2.5}
\]

这就是 Q3。

令

\[
s=\nu(b_1)\in\{0,1\}.
\]

则

\[
\nu(b_1)=s,\qquad
\nu(b_2)=s+a+M,\qquad
\nu(b_3)=s+M.
\tag{2.6}
\]

所以最大二进赋值恰在 \(b_2\) 取得，与 T8 相容。逐项既约性给出

\[
\boxed{a_2,a_3\ \text{均为奇数}.}
\tag{2.7}
\]

当 \(b_1=2\) 时还必须有 \(a_1\) 为奇数，故首块只能是 T12 中
\((5,2),(7,2),(9,2),(11,2),(13,2)\)；当 \(b_1=1\) 时八种
\(a_1=1,\ldots,8\) 都尚未由正规化排除。

### 2.2 Q 模板的实际分母位数窗

式 (2.5) 不能只保留二进赋值。两个真实窗口是

\[
\boxed{
10^{m-1}
\le 2^{s+a+M}q_0u_0
<10^m,
}
\tag{2.8}
\]

\[
\boxed{
10^{n-1}
\le 2^{s+M}gu_0
<10^n.
}
\tag{2.9}
\]

等价地，上界部分为

\[
\boxed{
2^{s+a+n}q_0u_0<5^m,\qquad
2^{s+m}gu_0<5^n,
}
\tag{2.10}
\]

下界部分为

\[
\boxed{
5^{m-1}\le2^{s+a+n+1}q_0u_0,\qquad
5^{n-1}\le2^{s+m+1}gu_0.
}
\tag{2.11}
\]

这些不等式确实同时限制 \(m,n,a,q_0,g,u_0\)，但它们只给出一个
无界指数锥，没有给出 \(m,n,a\) 的绝对上界。

Q 模板中的循环方程化为

\[
\boxed{
g(2^a q_0k-1)=5^{M-e}+2^a q_0Y.
}
\tag{2.12}
\]

其右边为奇数，因此没有额外的正二进赋值；阶段 I 的 Q 模板只有这一个
精确赋值型，而不是若干虚构的 \(a,m,n\) 固定切片。

## 3. G 模板正规化

### 3.1 阶段 I 核心引理 GN：G1–G4

假设 \(2\mid g\)。由两两互素性，

\[
2\nmid qr.
\]

式 (1.7) 给出 \(rv\mid b_1\le2\)。其中 \(r\) 为奇数，故

\[
r=1.
\]

又因 \(v\mid Y\)，且 \(v\mid b_1\)，得到

\[
\boxed{r=1,\qquad v\in\{1,2\}.}
\tag{3.1}
\]

这就是 G1。

若 \(v=2\)，则 \(v\mid b_1\) 强迫

\[
\boxed{b_1=2.}
\]

再由 \(\gcd(u,v)=1\)，

\[
\boxed{u\ \text{为奇数}.}
\tag{3.2}
\]

这就是 G2。若 \(v=1\)，则只得到

\[
\boxed{b_1\in\{1,2\},}
\tag{3.3}
\]

而 \(u\) 的二进指数必须保留。这是 G3。

统一写成

\[
\boxed{
g=2^ag_0,\qquad
u=2^cu_0,\qquad
v=2^d,
}
\tag{3.4}
\]

其中

\[
a\ge1,\qquad d\in\{0,1\},\qquad cd=0,
\tag{3.5}
\]

\[
q,g_0,u_0\ \text{均为奇数},\qquad
u_0=5^e,\quad0\le e\le M.
\tag{3.6}
\]

代入 (1.8) 得

\[
\boxed{
b_2=\frac{b_1qu}{v},\qquad
b_3=b_1gu.
}
\tag{3.7}
\]

这就是 G4。若仍记 \(s=\nu(b_1)\)，则

\[
\nu(b_2)=s+c-d,\qquad
\nu(b_3)=s+a+c.
\tag{3.8}
\]

因此：

- \(v=2\) 时 \(s=d=1,c=0\)，故 \(b_2\) 为奇数，\(b_3\) 为偶数；
  \(a_1,a_3\) 为奇数，而 \(a_2\) 的二进赋值暂不固定；
- \(v=1\) 时 \(a_3\) 总为奇数；
- \(v=1\) 时，除 \(b_1=1,c=0\) 外，\(b_2\) 为偶数，因而
  \(a_2\) 为奇数；
- \(b_1=2\) 时 \(a_1\) 为奇数。

G 模板的真实分母窗口为

\[
\boxed{
10^{m-1}\le
2^{s+c-d}qu_0
<10^m,
}
\tag{3.9}
\]

\[
\boxed{
10^{n-1}\le
2^{s+a+c}g_0u_0
<10^n.
}
\tag{3.10}
\]

## 4. 循环方程的四个精确二进状态

### 4.1 阶段 I 核心引理 EC：G5 的完整分类

在 G 模板中 \(r=1\)，循环方程是

\[
2^ag_0(kq-1)=U+qV.
\tag{4.1}
\]

因 \(k,q\) 都为奇数，令

\[
\lambda=\nu(kq-1)\ge1.
\tag{4.2}
\]

于是

\[
\boxed{
a+\lambda=\nu(U+qV).
}
\tag{4.3}
\]

这就是 G5。现在

\[
\nu(U)=M-c,\qquad
\nu(qV)=n-d.
\tag{4.4}
\]

必须区分以下四种且仅以下四种状态。

#### G–A：\(v=2\)

此时 \(d=1,c=0,b_1=2\)。有

\[
\nu(U)=M,\qquad \nu(qV)=n-1.
\]

两赋值不等，不发生消去。因此

\[
\boxed{
a+\lambda=n-1,\qquad
n=a+\lambda+1\ge3.
}
\tag{4.5}
\]

#### G–B：\(v=1,\ c<m\)

此时

\[
\nu(U)=M-c>n=\nu(qV),
\]

故

\[
\boxed{
a+\lambda=n.
}
\tag{4.6}
\]

#### G–C：\(v=1,\ c=m\)

此时两项赋值都为 \(n\)，是真正的共振状态。定义

\[
\boxed{
\eta=
\nu\left(\frac U{2^n}+q\frac V{2^n}\right)
=\nu\left(5^{M-e}+q5^n\right)\ge1.
}
\tag{4.7}
\]

于是

\[
\boxed{
a+\lambda=n+\eta.
}
\tag{4.8}
\]

这里的 \(\eta\) 不能省略或假定为 \(1\)。

#### G–D：\(v=1,\ c>m\)

此时

\[
\nu(U)=M-c<n=\nu(qV),
\]

故

\[
\boxed{
a+\lambda=M-c.
}
\tag{4.9}
\]

写

\[
j=c-m>0.
\]

则

\[
\boxed{
c=m+j,\qquad
n=j+a+\lambda,\qquad
1\le j\le n-2.
}
\tag{4.10}
\]

最后一个上界来自 \(a+\lambda\ge2\)，不是位数近似。

至此，任意 \((a,c,d,m,n)\) 已不再作为一个未分类的五元组保留，而是落入
G–A、G–B、G–C、G–D 四个精确赋值型。各型内部仍含无界参数；阶段 I
本身没有证明这些参数有界。

## 5. 三平方二进赋值定理

### 5.1 阶段 II 核心引理 TS

设整数 \(A,B,C\) 不全为零，并令

\[
h=\min(\nu(A),\nu(B),\nu(C)).
\]

写

\[
A=2^hA',\qquad B=2^hB',\qquad C=2^hC',
\]

则 \(A',B',C'\) 中至少一个为奇数。平方模 \(8\) 只能为

\[
0,\ 1,\ 4.
\]

若 \(A',B',C'\) 中恰有一个或三个奇数，则其平方和为奇数，故

\[
\nu(A'^2+B'^2+C'^2)=0.
\]

若恰有两个奇数，则两个奇平方模 \(8\) 之和为 \(2\)，第三个偶平方为
\(0\) 或 \(4\)，故平方和模 \(8\) 为 \(2\) 或 \(6\)，从而

\[
\nu(A'^2+B'^2+C'^2)=1.
\]

因此

\[
\boxed{
\nu(A^2+B^2+C^2)=2h+\varepsilon,
}
\tag{5.1}
\]

其中

\[
\boxed{
\varepsilon=
\begin{cases}
0,&\text{最小赋值项的个数为 }1\text{ 或 }3,\\
1,&\text{最小赋值项的个数为 }2.
\end{cases}
}
\tag{5.2}
\]

由于 \(t\) 为奇数，(1.12) 给出精确等式

\[
\boxed{
\nu(\Gamma)
=2\min(\nu(W_{12}),\nu(W_{13}),\nu(W_{23}))
+\varepsilon.
}
\tag{5.3}
\]

后文不仅比较最小赋值，还始终核对达到最小值的项数。

## 6. Q 模板完整分析

### 6.1 阶段 II 核心引理 QV：Q4 与三个归一化块

在 Q 模板中 \(r=v=1\)，\(q=2^aq_0\)，\(u=2^Mu_0\)。由 (1.13)，

\[
\Gamma
=uY\left(
99q^2uY-2qTY-2gT-2qgu
\right).
\tag{6.1}
\]

括号内四项的二进赋值依次为

\[
2a+M+n,\qquad
1+a+M,\qquad
1+m,\qquad
1+a+M.
\tag{6.2}
\]

因为 \(a,n\ge1\)，第三项的赋值 \(m+1\) 严格最小。因此

\[
\nu(\Gamma)
=(M+n)+(m+1)
=2m+2n+1.
\]

即

\[
\boxed{\nu(\Gamma)=2M+1.}
\tag{6.3}
\]

这严格证明 Q4。

逐项既约性已经给出 \(a_2,a_3\) 为奇数。把三个 \(W\) 除以
\(2^M\)，得到精确整数式

\[
\boxed{
\frac{W_{12}}{2^M}
=g\left(
5^M a_2
-2^{M+n+1+2a}5^{n+1}q_0^2u_0^2a_1
\right),
}
\tag{6.4}
\]

\[
\boxed{
\frac{W_{13}}{2^M}
=2^aq_0\left(
5^M a_3
-2^Mg^2u_0^2a_1
\right),
}
\tag{6.5}
\]

\[
\boxed{
\frac{W_{23}}{2^M}
=u_0\left(
2^{n+1+2a}5^{n+1}q_0^2a_3
-g^2a_2
\right).
}
\tag{6.6}
\]

由此

\[
\boxed{
\nu(W_{12})=M,\qquad
\nu(W_{13})=M+a,\qquad
\nu(W_{23})=M.
}
\tag{6.7}
\]

所以

\[
\boxed{
\min\nu(W_{ij})=M,
}
\tag{6.8}
\]

且除以 \(2^M\) 后恰有 \(W_{12},W_{23}\) 两项为奇数。
三平方定理于是给

\[
\nu(W_{12}^2+W_{13}^2+W_{23}^2)=2M+1,
\]

与 (6.3) 精确相符。

这说明 Q 模板中的“三个平方高二进整除”没有落到 \(a_1\)：
完整的 \(2^M\) 已由 \(u\) 吸收。结论 \(a_2,a_3\) 为奇数也已经由
\(\gcd(a_i,b_i)=1\) 蕴含，不能算新的关闭机制。

### 6.2 模 \(16\) 的非平凡数字块门

虽然模 \(8\) 的最小项计数自动相符，模 \(16\) 仍给出一个精确必要条件。
由 (6.1) 直接除以 \(2^{2M}\) 可得

\[
\boxed{
\frac{\Gamma}{2^{2M}}
\equiv-2gu_0\,5^M\pmod{16}.
}
\tag{6.9}
\]

又因奇数的四次方模 \(16\) 为 \(1\)，由 (6.4)–(6.6)

\[
\left(\frac{W_{12}}{2^M}\right)^2
\equiv g^2 5^{2M}a_2^2\pmod{16},
\]

\[
\left(\frac{W_{23}}{2^M}\right)^2
\equiv u_0^2a_2^2\pmod{16},
\]

\[
\left(\frac{W_{13}}{2^M}\right)^2
\equiv
\begin{cases}
4\pmod{16},&a=1,\\
0\pmod{16},&a\ge2.
\end{cases}
\]

由于 \(t^2\equiv1\) 或 \(9\pmod{16}\)，而
\(\Gamma/2^{2M}\) 恰被 \(2\) 整除，乘以 \(t^2\) 不改变其模 \(16\)
类。因此得到

\[
\boxed{
-2gu_0\,5^M
\equiv
a_2^2\left(g^2 5^{2M}+u_0^2\right)
+4\mathbf 1_{a=1}
\pmod{16}.
}
\tag{6.10}
\]

这是对 \(a_2\bmod8\) 的真实门，不只是“\(a_2\) 为奇数”。
但 \(a_2^2\bmod16\in\{1,9\}\)，而 \(g,u_0\) 的奇数剩余类仍可变化；
(6.10) 不限制 \(a\) 的大小，也不产生 \(m,n\) 的统一关系或上界。

### 6.3 Q 模板的停止点

Q 模板最终仍须同时满足：

1. 循环方程 (2.12)；
2. 分母窗口 (2.8)–(2.11)；
3. 分子窗口 (1.10)；
4. 十三首块中与 \(b_1\) 相容的类型；
5. 逐项既约；
6. 模 \(16\) 门 (6.10)；
7. 完整整数等式 (1.12)，而不只是两边赋值相同。

这些条件没有推出 \(a,m,n\) 的统一上界，也没有排除 Q 模板。

一个用于攻击错误关闭的精确辅助数据为

\[
\begin{gathered}
m=n=3,\quad b_1=1,\quad q=8,\quad g=15,\quad u=64,\quad r=v=1,\\
U=15625,\quad V=1000,\quad k=197,\\
b_2=512,\quad b_3=960.
\end{gathered}
\tag{6.11}
\]

它满足实际 \(U,V\) 定义、循环方程

\[
15(197\cdot8-1)=15625+8\cdot1000,
\]

以及两个真实分母位数窗。再取例如

\[
(a_1,a_2,a_3)=(2,11,1001),
\]

则分子位数、逐项既约、Q 的奇偶型和模 \(16\) 门也相容，并有

\[
(\nu(W_{12}),\nu(W_{13}),\nu(W_{23}))=(6,9,6),
\]

\[
\nu(\Gamma)=13
=\nu(W_{12}^2+W_{13}^2+W_{23}^2).
\]

这组数据不满足完整主等式，因而不是原题解；它只严格说明：
阶段 I 的十进制定义、实际位数窗和阶段 II 的全部二进门本身不能关闭 Q。

## 7. G 模板四状态分析

### 7.1 阶段 II 核心引理 GV：统一精确公式

在 G 模板中 \(r=1\)。令

\[
e_i=\nu(a_i).
\]

由 (1.14)–(1.16)，三个赋值由以下整数差精确决定：

\[
\boxed{
\begin{aligned}
W_{12}
&=2^ag_0\Bigl(
2^{M+2d}5^M a_2
-2^{n+1+2c}5^{n+1}q^2u_0^2a_1
\Bigr),\\
W_{13}
&=q2^d\Bigl(
2^M5^M a_3
-2^{2a+2c}g_0^2u_0^2a_1
\Bigr),\\
W_{23}
&=2^cu_0\Bigl(
2^{n+1}5^{n+1}q^2a_3
-2^{2a+2d}g_0^2a_2
\Bigr).
\end{aligned}
}
\tag{7.1}
\]

两项赋值相等时，(7.1) 保留完整奇数差；后文不把它替换成错误的较小值。

下面逐状态分析。

### 7.2 G–A：\(v=2\)

这里

\[
d=s=1,\qquad c=0,\qquad e_1=e_3=0,
\qquad n=a+\lambda+1.
\tag{7.2}
\]

若 \(\lambda>1\)，(1.13) 的括号中
\(-2qguv\) 具有唯一最小赋值 \(a+2\)，故

\[
\boxed{\nu(\Gamma)=n+a+2=2a+\lambda+3.}
\tag{7.3}
\]

同时

\[
\nu(W_{12})=a+n+1,
\tag{7.4}
\]

\[
\nu(W_{13})
=1+\nu\left(2^M\cdot\mathrm{odd}-2^{2a}\cdot\mathrm{odd}\right),
\tag{7.5}
\]

\[
\nu(W_{23})
=\nu\left(2^{n+1}\cdot\mathrm{odd}
-2^{2a+2+e_2}\cdot\mathrm{odd}\right).
\tag{7.6}
\]

若 \(a<\lambda+1\)，唯一最小项是 \(W_{13}\)，其赋值为 \(2a+1\)。
三平方定理要求

\[
2a+\lambda+3=2(2a+1),
\]

故

\[
\lambda=2a-1.
\]

若 \(a=\lambda+1\)，最小项个数为两个，但两边赋值不相符；若
\(a>\lambda+1\)，右边的最小平方赋值已经大于 (7.3)。因此

\[
\boxed{
\lambda>1
\Longrightarrow
a\ge2,\quad\lambda=2a-1,\quad n=3a.
}
\tag{7.7}
\]

若 \(\lambda=1\)，则 \(n=a+2\)，(1.13) 中两项在最低层相消。定义

\[
\boxed{
\theta_A=
\nu\Bigl(
99q^2u_0 5^n-qg_0u_0
-2^{m+1}g_0 5^m
-2^{m+2}q5^M
\Bigr)\ge1.
}
\tag{7.8}
\]

于是

\[
\nu(\Gamma)=2n+\theta_A.
\tag{7.9}
\]

精确比较最小项个数得到：

\[
\boxed{
\lambda=1
\Longrightarrow
\begin{cases}
a=1&\text{矛盾},\\
a=2&\theta_A=3,\\
a\ge3&\theta_A=2.
\end{cases}
}
\tag{7.10}
\]

因此 G–A 中整个 \(a=1\) 子模板无解。其 \(m,n\) 在分析前并未固定，
这是一个完整无界子状态的关闭。

剩余 G–A 只有

\[
\boxed{
\begin{array}{c|c|c}
\text{状态}&\lambda&n\\ \hline
\mathrm{A1}&1&a+2\\
\mathrm{A2}&2a-1&3a
\end{array}
\qquad a\ge2,
}
\tag{7.11}
\]

并在 A1 中保留 (7.10) 的真实高阶消去条件。

### 7.3 G–B：\(v=1,\ c<m\)

循环方程给出 \(n=a+\lambda\)。

#### 7.3.1 非退化部分 \(c>0\)

此时 \(a_2,a_3\) 都为奇数。若 \(\lambda>1\)，

\[
\boxed{
\nu(\Gamma)=2a+\lambda+2c+1.
}
\tag{7.12}
\]

在 \(a<\lambda+1\) 时，\(W_{23}\) 是唯一最小项，赋值为 \(c+2a\)；
三平方定理迫使

\[
\lambda=2a-1.
\]

其余 \(a\ge\lambda+1\) 的赋值室全部矛盾。因此

\[
\boxed{
c>0,\ \lambda>1
\Longrightarrow
a\ge2,\quad\lambda=2a-1,\quad n=3a-1.
}
\tag{7.13}
\]

若 \(\lambda=1\)，定义真实消去参数

\[
\boxed{
\theta_B=
\nu\Bigl(
qu_0(99q5^n-g_0)
-2^{m-c}g_0 5^m
-2^{m-c+1}q5^M
\Bigr)\ge1.
}
\tag{7.14}
\]

则

\[
\nu(\Gamma)=2(c+n)+\theta_B.
\tag{7.15}
\]

最小项个数给出

\[
\boxed{
c>0,\ \lambda=1
\Longrightarrow
\begin{cases}
a=1&\text{矛盾},\\
a=2,\ c=m-1&\theta_B=2,\\
a=2,\ c\le m-2&\text{保留 (7.1)、(7.15) 的精确共振门},\\
a\ge3,\ c=m-1&\theta_B=3,\\
a\ge3,\ c\le m-2&\theta_B=2.
\end{cases}
}
\tag{7.16}
\]

因此 \(0<c<m,\ a=1\) 整个无界子模板关闭。

#### 7.3.2 边界部分 \(c=0,b_1=2\)

此时 \(e_1=e_2=e_3=0\)。同样的最小项计数给出

\[
\boxed{
\begin{array}{c|c}
\lambda=1&
\theta_B=
\begin{cases}
1,&a=1,\\
2,&a\ge2,
\end{cases}\\[2mm]
\lambda>1&\lambda=2a.
\end{array}
}
\tag{7.17}
\]

在第二行中 \(n=a+\lambda=3a\)。注意这里得到的是
\(\lambda=2a\)，不是 \(2a-1\)；原因是 \(c=e_1=e_2=0\) 时
\(W_{13},W_{23}\) 恰有两个最小项，必须使用 \(\varepsilon=1\)。

#### 7.3.3 唯一未完全线性化的边界 \(c=0,b_1=1\)

此时 \(b_2=qu_0\) 为奇数，所以 \(e_2=\nu(a_2)\) 不由既约性固定。
T12 只把

\[
e_1\in\{0,1,2,3\}
\tag{7.18}
\]

固定到四个首块类。若 \(\lambda>1\)，

\[
\nu(\Gamma)=2a+\lambda+1,
\tag{7.19}
\]

而

\[
\boxed{
\begin{aligned}
\nu(W_{12})
&=a+\nu\left(
2^{M+e_2}\cdot\mathrm{odd}
-2^{n+1+e_1}\cdot\mathrm{odd}
\right),\\
\nu(W_{13})
&=\nu\left(
2^M\cdot\mathrm{odd}
-2^{2a+e_1}\cdot\mathrm{odd}
\right),\\
\nu(W_{23})
&=\nu\left(
2^{n+1}\cdot\mathrm{odd}
-2^{2a+e_2}\cdot\mathrm{odd}
\right).
\end{aligned}
}
\tag{7.20}
\]

令三式最小值为 \(h_B\)，并按达到最小值的项数定义
\(\varepsilon_B\in\{0,1\}\)。完整必要条件是

\[
\boxed{
2a+\lambda+1=2h_B+\varepsilon_B.
}
\tag{7.21}
\]

非共振室中，(7.21) 把 \(\lambda\) 压到有限个仿射候选

\[
\lambda\in
\{2a+2e_1-1,\ 2a+2e_1,\
2a+2e_2-1,\ 2a+2e_2\},
\tag{7.22}
\]

但 \(e_2\) 随 \(m\) 仍可增长。两项赋值相等时必须返回 (7.20)
中的显式奇数差，不能删去高阶消去。

当 \(\lambda=1\) 时则以 (7.14)（取 \(c=0\)）定义 \(\theta_B\)，并用

\[
\boxed{
2(a+1)+\theta_B=2h_B+\varepsilon_B
}
\tag{7.23}
\]

替代 (7.21)。

这就是 G–B 剩余的最小精确状态；本文没有从
\(a_2<10^{m-1}\) 推出 \(e_2\) 的统一绝对上界。

### 7.4 G–C：\(v=1,\ c=m\)

共振参数 \(\eta\) 见 (4.7)。这里 \(a_2,a_3\) 为奇数，并且

\[
a+\lambda=n+\eta.
\tag{7.24}
\]

式 (1.13) 的前两项合并后赋值恰为 \(M\)。后两项合并后赋值为

\[
m+a+1+\eta.
\tag{7.25}
\]

这里使用了

\[
\nu(5^m+qu_0)
=\nu(5^{M-e}+q5^n)
=\eta;
\tag{7.26}
\]

等式成立是因为把两边分别乘以适当的奇数 \(5\) 次幂后得到同一个奇数和，
不会改变二进赋值。

因此：

\[
\boxed{
\nu(\Gamma)=
\begin{cases}
2M,&\lambda<2\eta+1,\\
2M-(\lambda-2\eta-1),&\lambda>2\eta+1,\\
2M+\kappa,&\lambda=2\eta+1,
\end{cases}
}
\tag{7.27}
\]

其中等号共振时

\[
\kappa\ge1
\tag{7.28}
\]

是把 (1.13) 除以 \(2^M\) 后两个奇数主项之差的真实赋值。

另一方面

\[
\nu(W_{12})=a+M,
\tag{7.29}
\]

\[
\nu(W_{13})
=\nu\left(
2^M\cdot\mathrm{odd}
-2^{2a+2m+e_1}\cdot\mathrm{odd}
\right),
\tag{7.30}
\]

\[
\nu(W_{23})
=m+\nu\left(
2^{n+1}\cdot\mathrm{odd}
-2^{2a}\cdot\mathrm{odd}
\right).
\tag{7.31}
\]

三平方定理把 G–C 完整压成以下三室：

\[
\boxed{
\begin{array}{c|c}
\mathrm{C1}&
\lambda<2\eta+1,\quad 2a>n,\quad a+\lambda=n+\eta;\\[1mm]
\mathrm{C2}&
a\ge\eta+2,\quad
\lambda=2a-1,\quad
n=3a-1-\eta;\\[1mm]
\mathrm{C3}&
a=\eta+1,\quad
\lambda=2a-1,\quad
n=2a,\quad
\kappa=1.
\end{array}
}
\tag{7.32}
\]

证明要点如下。

- 第一行中 \(\nu(\Gamma)=2M\)，故三个 \(W\) 的最小赋值必须恰为
  \(M\)，且只能有一个最小项；这等价地强迫 \(2a>n\)。
- 第二行中 \(2a<n\)，唯一最小项是 \(W_{23}\)，赋值为 \(m+2a\)；
  比较两边得到 \(\lambda=2a-1\)。
- 等号室中，若 \(2a\ne n\)，右边平方和的赋值严格小于或等于
  \(2M\)，不能等于 \(2M+\kappa\)；故 \(2a=n\)，再由最小项个数
  得 \(\kappa=1\)。

G–C 仍含无界的 \(\eta,a,m\)，所以 (7.32) 是有限赋值室，不是有限指数集。

### 7.5 G–D：\(v=1,\ c>m\)

写

\[
c=m+j,\qquad
1\le j\le n-2,\qquad
n=j+a+\lambda.
\tag{7.33}
\]

此时 \(a_2,a_3\) 为奇数。式 (1.13) 中
\(-2gv^2T\) 具有唯一最小赋值 \(m+a+1\)，因此

\[
\boxed{
\nu(\Gamma)
=2M-\lambda+1.
}
\tag{7.34}
\]

三个 \(W\) 满足

\[
\nu(W_{12})=a+M,
\tag{7.35}
\]

\[
\nu(W_{13})
=\nu\left(
2^M\cdot\mathrm{odd}
-2^{2a+2c+e_1}\cdot\mathrm{odd}
\right),
\tag{7.36}
\]

\[
\nu(W_{23})
=c+\nu\left(
2^{n+1}\cdot\mathrm{odd}
-2^{2a}\cdot\mathrm{odd}
\right).
\tag{7.37}
\]

按 \(2a<n+1\)、\(2a=n+1\)、\(2a>n+1\) 分室，并在每室内比较
\(W_{13},W_{23}\) 的最小项及其个数，最终恰得

\[
\boxed{
a\ge2,\qquad
\lambda\in\{1,\,2a-1\}.
}
\tag{7.38}
\]

更具体地，

\[
\boxed{
\begin{array}{c|c|c}
\text{状态}&\lambda&n\\ \hline
\mathrm{D1}&1&j+a+1\\
\mathrm{D2}&2a-1&j+3a-1
\end{array}
\qquad
c=m+j.
}
\tag{7.39}
\]

若 \(a=1\)，则 \(\lambda=1\) 正落在两个最小项但赋值不符的边界，
而 \(\lambda>1\) 又不能等于 \(2a-1=1\)。故

\[
\boxed{
v=1,\ c>m,\ a=1
\quad\text{整个无界子模板无解}.
}
\tag{7.40}
\]

实际分母窗口没有排除 D1、D2。它只额外给出

\[
2^{s+m+j}u_0<10^m,\qquad
2^{s+a+m+j}g_0u_0<10^n,
\tag{7.41}
\]

其中第一式限制 \(j\) 相对于 \(m\)，但 \(m\) 本身仍无界。

## 8. 十三种第一块与位数窗收束

### 8.1 十三首块的二进类

T12 的十三种首块实际归并为：

\[
\boxed{
\begin{array}{c|c|c}
b_1&\nu(a_1)&a_1\\ \hline
1&0&1,3,5,7\\
1&1&2,6\\
1&2&4\\
1&3&8\\
2&0&5,7,9,11,13
\end{array}
}
\tag{8.1}
\]

它们在两个模板中的作用如下。

1. Q 模板：
   \(b_1=1\) 时四个二进类都保留；\(b_1=2\) 时只保留最后一行。
   由于 \(W_{12},W_{23}\) 的最低层都落在奇数 \(a_2\)，而
   \(W_{13}\) 的额外二进幂来自 \(q\)，没有出现
   \(2^h\mid a_1\) 的新条件。
2. G–A：
   必有 \(b_1=2\)，所以只使用最后一行；全部 \(a_1\) 都是奇数。
3. G–B、G–C、G–D：
   \(b_1=2\) 时仍只用最后一行；
   \(b_1=1\) 时 \(e_1\) 被严格限制为 \(0,1,2,3\)，并已经代入
   (7.20)、(7.30)、(7.36)。

因此本文确实使用了十三首块，而不只是 \(b_1\le2\)。不过这些固定
\(e_1\) 没有把剩余的 \(a,\eta,j,m\) 压成有限集合。

### 8.2 四个真实数字块窗

所有剩余状态都必须同时满足

\[
\boxed{
10^{m-2}\le a_2<10^{m-1},\qquad
10^n\le a_3<10^{n+1},
}
\tag{8.2}
\]

以及 Q 的 (2.8)–(2.9) 或 G 的 (3.9)–(3.10)。

逐状态检查如下。

- Q 中 \(u\) 吸收 \(2^M\)，但两个上界只化为 (2.10)；
  它们允许 \(m,n\) 沿一个无界锥共同增长。
- G–A 的剩余 A1、A2 分别有 \(n=a+2\)、\(n=3a\)；
  \(b_3=2^{a+1}g_0u_0\) 的 \(n\) 位窗口与两条关系均相容，
  没有给 \(a\) 绝对上界。
- G–B 中 \(c<m\)，故 \(2^c\) 本身不会超过 \(m\) 位块的统一上界；
  唯一例外 \(c=0,b_1=1\) 还保留随 \(m\) 变化的 \(e_2=\nu(a_2)\)。
- G–C 中 \(c=m\)，但 \(2^m<10^m\) 对所有 \(m\) 成立；
  因而 \(b_2\) 窗不排除共振室。
- G–D 中 \(c=m+j\) 给出 (7.41)，只把 \(j\) 线性约束于 \(m\)，
  不产生统一 \(j\) 或 \(n\) 上界。

因此不存在“高二进整除超过数字块上界”的统一矛盾。

### 8.3 对错误数值关闭的辅助反例

以下数据满足 G–A 的实际十进制定义、循环方程、分母位数窗以及
阶段 II 的剩余赋值门：

\[
\begin{gathered}
m=2,\quad n=4,\quad v=b_1=2,\quad
q=3,\quad g=100,\quad u=5,\\
a=2,\quad \lambda=1,\quad k=717,\\
b_2=15,\quad b_3=1000.
\end{gathered}
\tag{8.3}
\]

确有

\[
100(717\cdot3-1)
=\frac{10^6}{5}+3\frac{10^4}{2},
\]

且这里 \(\theta_A=3\)，正好命中 (7.10)。取

\[
(a_1,a_2,a_3)=(5,7,10001)
\]

时，四个数字块窗和逐项既约均成立，并且

\[
\nu(\Gamma)=11,\qquad
(\nu(W_{12}),\nu(W_{13}),\nu(W_{23}))=(7,5,5),
\]

故三平方赋值门也精确相符。它仍不满足完整等式 (1.12)，所以不是原题解。
它只反驳“G–A 的剩余状态会被位数窗自动排除”的错误推断。

本文没有用这类有限数据支持任何全局存在结论。

## 10. 主动反例攻击

### 10.1 是否误把 \(rv\mid b_1\) 总写成 \(r=v=1\)

没有。

- Q 中先证明 \(r,v\) 都为奇数，才由 \(rv\mid b_1\in\{1,2\}\)
  得到 \(r=v=1\)。
- G 中 \(r\) 为奇数，所以 \(r=1\)，但 \(v=2,b_1=2\) 被完整保留。

### 10.2 Q 中 \(u\) 的完整二进幂是否使三平方整除成为恒等

是，最低层确实被 \(u\) 吸收。精确结果是

\[
(\nu(W_{12}),\nu(W_{13}),\nu(W_{23}))=(M,M+a,M),
\]

所以仅从 \(2^M\mid W_{ij}\) 不能得到新结论。本文没有把这一恒等性
包装成对 \(a_1\) 的下降；只保留了更高一层的模 \(16\) 门 (6.10)。

### 10.3 G 中相等赋值是否遗漏高阶消去

没有。本文显式保留：

\[
\eta,\quad\theta_A,\quad\theta_B,\quad\kappa,
\]

以及 (7.1)、(7.20) 中的奇数差。所有相等赋值室都没有直接取较小值。

### 10.4 是否把三个平方和的赋值写成任意整数

没有。全文使用

\[
\nu(\Sigma W^2)=2h+\varepsilon,\qquad\varepsilon\in\{0,1\},
\]

并按最小项个数决定 \(\varepsilon\)。例如 (7.17) 的
\(\lambda=2a\) 正是两个最小项造成的 \(+1\)，若忽略项数会误得
\(\lambda=2a-1\)。

### 10.5 是否忘记 \(t\) 为奇数

没有。由 \(2\mid L\) 和 T8，Q、G 中始终使用 \(\nu(t)=0\)，所以
\(\nu(t^2\Gamma)=\nu(\Gamma)\)。

### 10.6 是否只得到逐项既约已蕴含的奇偶性

Q 的最低层奇偶性确实由既约性自动给出，本文明确将其降级。新增内容是：

- Q 的精确三项赋值；
- Q 的模 \(16\) 门；

## 11. 最终分类 E1–E6 与剩余最小系统

### 11.1 分类

本轮达到

\[

具体关闭：

\[

并在这些状态之外排除了所有不属于第 7 节有限仿射赋值室的参数室。

为什么不是 E1：

- Q、G 都没有整体关闭。

为什么不是 E2：

- 没有关闭其中一个完整模板；

为什么高于 E5：

- (11.1) 是完整无界子模板的严格排除，不只是新赋值公式。

没有找到合法原题解。
