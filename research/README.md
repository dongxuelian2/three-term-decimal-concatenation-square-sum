# Research tree

This directory is organized by mathematical containment. Start with the parent
problem, then follow the exact-lift, denominator, A1, J2, or critical-template
branch that matches the question.

Active files use mathematical names. Historical campaign and round names are
aliases only; the verbatim source export is preserved under
[`archive/strict-layer-proof-research/`](archive/strict-layer-proof-research/)
and mapped in [`../provenance/MIGRATION_MAP.tsv`](../provenance/MIGRATION_MAP.tsv).

Each branch keeps results, failures, attempts, computations, and archival
records close to the problem they concern. A failure records reusable negative
knowledge about a delimited route; it is not a claim that the original problem
has been disproved.
